# Title
Musualizer

## Repository
https://github.com/jankee12c/pfda-finalproject-jc26

## Description
This program will have the ability to play music and show computer generated visuals that will accompany it.

## Features
- Feature 1
	- Drag and drop .mp3 files onto a designated folder to play them in software.
- Feature 2
	- Add custom visualizer files to another folder that will let you toggle between the built in ones and user made ones.
- Feature N 
	- Cycle, Play, and Pause music in software, with a setting that allows you to toggle between visuals in folder.

## Challenges
- Learning to implement music playing function with music player options
- Designing some UI elements, either through code or drawn in a texture atlas
- Reading PyGame and possibly OpenGL documentation if 3D were to be implemented in the visuals

## Outcomes
Ideal Outcome:
- Having the music player function with player controls working and having at least 2 premade visuals to cycle through.

Minimal Viable Outcome:
- Music needs to just at least play and one visual is present.

## Milestones

- Week 1
  1. Implement music playing function (and to have program read other folders.)
  2. Get music player controls to work, such as Play, Pause, and Skip. (all this programmed as a terminal program to test.)

- Week 2
  1. Display basic music controls with mouse support in a window.
  2. Display a "prototype" visual to see if it works, having a sort of layer system in place.

- Week N (Final)
  1. Adding Visuals 1 and 2.
  2. Refine UI design
